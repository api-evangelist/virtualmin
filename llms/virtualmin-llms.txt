# Virtualmin

> Open-source web hosting control panel for Linux/BSD built on Webmin. Manages virtual servers, DNS, email, FTP, databases, SSL, and WordPress from one interface, in a community GPL edition and a commercial Pro edition. Automation is exposed through a command-line API and an HTTP-based Remote API (remote.cgi on port 10000) covering ~200 documented programs. Self-hosted; no central hosted API. Generated by the API Evangelist enrichment pipeline from public docs.

## API
- [Remote API](https://www.virtualmin.com/docs/development/remote-api/): HTTP API at https://<host>:10000/virtual-server/remote.cgi. Pass `program=<name>` plus that program's CGI params. HTTP Basic auth (Webmin master admin). Output: text (default), json=1, xml=1, perl=1; `multiline` on list-* calls.
- [Command Line API](https://www.virtualmin.com/docs/development/command-line-api/): `virtualmin <operation> --flags`, run as root.
- [API Programs reference](https://www.virtualmin.com/docs/development/api-programs/): ~200 programs (create-domain, list-domains, create-user, create-alias, create-database, generate-letsencrypt-cert, backup-domain, ...).
